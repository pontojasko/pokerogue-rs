# Imported game data

`src/generated_data.rs` and `../pokerogue-tests/fixtures/imported-demo-data.csv` are generated by `node scripts/import_demo_data.mjs` from the local TypeScript checkout pinned in `AGENTS.md`. `src/generated_modifier_pools.rs` and `../pokerogue-tests/fixtures/modifier-pools.csv` are extracted in original order by `node scripts/import_modifier_pool_catalog.mjs`.

The current import includes every Pokémon pool bucket for the initial `TOWN` biome: all 9 rarity tiers × 5 `TimeOfDay` labels, including empty pools. The union contributes 67 encounter species plus the two demo starters (69 total), including original base friendship and catch rate, 934 numeric level-up rows, 3,288 ordered species TM rows, 277 TM-tier records and 439 move definitions with maximum PP. It also extracts 86 ordered player modifier-pool declarations across COMMON through MASTER, preserving IDs, tier/order, literal weights and max weights; callback weights are marked dynamic. Original enum symbols and numeric IDs are retained. Rust exposes ID lookups, pool buckets, level-up moves and bounded TM compatibility queries; the Town run is implemented through wave 10. Runtime uses checked-in data and has no Node/network dependency. Re-run the respective generator after changing the subset; use each script's `--check` to verify reproducibility without modifying files.

The importer executes the pinned `Arena.generateNonBossBiomeTier` and `generateBossBiomeTier` method bodies over their complete base roll ranges to derive tier intervals and weights (normal denominator 512, boss denominator 64). It also records the source time-bucket merge order and metadata for override species, forced daily tier, boss table, and luck-adjusted roll bound. Those dynamic conditions are not executed by the Rust data layer.

Species and move display labels are title-cased from their source IDs; this is not a localization import. TM compatibility currently uses direct base-species TM lists, imported numeric level-up rows, known/used move filters, tier IDs and the source `isUnimplemented` flag. Evolution-chain learnset exclusions, prevolution TM inheritance, forms, fusions, challenge overrides, used-TM persistence and non-Town biomes remain out of scope. Move effects/targets remain in the existing Rust model and are not generated here. Data provenance follows the original game source and this workspace's AGPL-3.0-only license. This crate contains no sprite or other visual assets; see root `ASSET_CREDITS.md` for unresolved asset redistribution rights.
