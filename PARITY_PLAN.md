Reference: `pagefaultgames/pokerogue` commit `7c0881255af5cd51992e513ff93c2f71adbe40e0` in `original/`. Phaser RNG reference: Phaser `4.2.1` `RandomDataGenerator.js`, matching the pinned PokéRogue lockfile. Do not report 1:1 equivalence unless the relevant deterministic scenarios were run against these sources.

This file is the durable evidence ledger: source-executed fixtures, source-inspected behavior, Rust-only checks, and unsupported cases must remain distinguishable. Current implementation snapshot and next task are in `PORTING_PROGRESS.md`; milestone ordering is in `ROADMAP.md`.

## Implemented

- **Encounter-entry fixtures (source methods, controlled RNG context):** `scripts/generate_town_encounter_fixture.mjs` runs the pinned constructor's 16 seeded `randomString` draws and `Battle.getLevelForWave` inside the wave-offset stream, then restores the wave RNG and runs `Arena.randomSpecies`, tier methods, `Pokemon.calculateStats`, and `Pokemon.getExpValue` for Town DAY waves 1–20. Rust compares battle seed, level, tier roll/name, species ID/name and pool index, available/projected moves, six stats, RNG outputs and base EXP. The harness forces single battles and excludes Mystery Encounters, so it does not prove normal Classic seed-to-encounter parity across `checkIsDouble` or Mystery Encounter selection. Zero IVs, neutral nature, no modifiers and no legendary/form reroll are controlled. Combat RNG is initialized from the generated Battle seed in Rust; complete Phaser phase/battle RNG parity is still open.
- **Bounded run progression (Rust-only battle outcome):** encounter generation and next-wave creation through wave 20 are tested. `MiniRunSeed0001` wins and resumes the ten-wave mode. The old 20-wave policy fixture `MiniRunSeed0667` was invalidated by switching combat RNG to the source-generated battle seed; it now loses before wave 20. A deterministic 20-wave route is being requalified. Any successful route/policy remains Rust-only and does not validate TypeScript battle outcomes or full Phaser phase ordering.
- **EXP data evidence:** the importer executes pinned `getLevelTotalExp` for all six growth rates and levels 1–100; all 600 values are checked in `exp-thresholds.csv`. `Pokemon.getExpValue` is directly executed for the generated wave fixtures. Bounded participant shares, level caps and state changes have method-level fixtures below; full run outcome/phase parity remains open.
- **XP level caps and `addExp` (source-executed methods):** `scripts/generate_exp_cap_fixture.mjs --check` executes the pinned `BattleScene.getMaxExpLevel` and `Pokemon.addExp` bodies in a minimal Classic context. Fixture cases cover the wave-group cap at waves 1/10/11/20, positive override, ignored cap, crossing a threshold, cap clamping, and level 100. - **EXP/LevelUp phase methods (source-executed isolated callbacks):** `scripts/generate_exp_phase_fixture.mjs --check` executes pinned `ExpPhase.start`, captures and invokes its UI callback, runs original `Pokemon.addExp`, and records the queued `LevelUpPhase(partyIndex=1,last=5,new=8)` plus phase completion. ## Partial equivalence and test limits

- Rust hit/miss tests use the original formula and actual Phaser random outputs, but do not invoke `Move.calculateBattleAccuracy` or `MoveEffectPhase.hitCheck` in the full Phaser scene. The upstream `original/node_modules` is not installed, and the scene test harness has not been set up.
- The Phaser RNG algorithm and PokéRogue's per-battle turn seed shift are ported; tests cover its numeric outputs and turn reset. The full run seed/battle seed creation chain and random calls before battle start are not reproduced. The demo intentionally supplies a fixed seed.
- Only the default ACC/EVA stage formula is active. The debug-only Sand Attack can modify accuracy stages; ordinary movesets remain as declared in the local demo data. Core exit hooks mirror inspected reset timing and Baton Pass copying for the two modeled stats. Switch-versus-basic-FIGHT turn behavior is modeled, but opponent move selection and complete TypeScript phase order are not. Base demo moves all have 100 accuracy, so neutral-stage attacks hit every time although they still consume the original accuracy RNG draw.
- Enemy AI is limited to the original wild `SMART_RANDOM` subset. The KO filter uses the core fixed-stat/fixed simulated-roll damage path; ability/item/attribute/critical/weather/terrain/conditional-move eligibility and full target selection are not equivalent. `ATTACKER` target exclusion is implemented, but Counter's condition and variable counter-damage mechanics are not. Usability queues, Encore, mixed attack/status candidate scoring and status moves outside Growl/Tail Whip/Leer remain incomplete.
- Mandatory faint replacement is modeled for one active player battler and a local party up to six members. It uses HP as the reserve-eligibility check; challenge legality, double/simultaneous faints, instant revival, post-faint hooks, and full deferred phase-queue continuation are not equivalent. The actual Phaser phase manager and UI were not executed.
- Basic two-actor FIGHT ordering now matches extracted speed/priority/tie methods. The local battle seed currently stands in for original `waveSeed`; battle seed/wave seed generation is not equivalent. Timing overrides, priority-bracket modifiers, speed-affecting abilities/items/status/weather, Trick Room, set-order overrides, and multi-actor/multiple-action queues are not implemented. Tie shuffling uses a separate offset-seeded Phaser stream and does not consume ordinary turn RNG.
- RNG order is matched for a single-target basic move check followed by damage. Multi-target/multi-hit, retries, and other systems that add random draws are not equivalent yet.
- Damage does not yet include move accuracy attributes, status-dependent modifiers, abilities, held items, weather, critical hits, screens, or other battle effects.

- Encounter selection and local 10/20-wave Town DAY runs are playable for deterministic seeds; waves 1–20 have source-executed encounter fixtures and boss helper fixtures. The full run loop is Rust-only. Fixed EXP Charm schedule and a bounded ordinary Poké Ball action are implemented. Natural COMMON offers plus a bounded GREAT subset (now including source-seeded Full Restore) are integrated; other higher-tier SelectModifierPhase offers/rerolls, shop, capture status/shiny/dex modifiers, full-party box/replacement, special boss exceptions, luck/daily/override paths and complete offline content extraction remain unsupported.
- Beyond the imported first-wave Town pool union, other biomes and localized names remain unimplemented.
- Symbolic relearn/evolution entries, regional forms, and trainer pools are not imported. Direct TMs plus source-derived direct prevolution links are imported for the bounded Town species set; TM inheritance is recursive over the imported family slice. Tier weights are base source bands; luck adjustment and boss/daily/override conditions are recorded but not applied. Encounter tier/species selection, level formula, RNG consumption, and actual wave execution are not implemented or claimed as parity.
- ARM Linux/R36S device validation. The architecture remains split from the renderer; no 32-bit userspace or Macroquad support is assumed.
